07四条买方判断（含可证伪条件）

按五要素呈现：每条挂量化锚 + 定性置信度 + 证伪条件。观点 · by_claude
置信度：高

① 全球格局：开源-闭源差距压缩到一个身位，且首次在成本前沿反超

AA 指数差 2.8 分（一年前约 10 分）；GDPval Elo 差 61；BrowseComp / WebDev Arena 单项第一；单任务成本为闭源旗舰 1/2~1/10。闭源 API 溢价还能收的部分只剩：研究级推理、过程可靠性、生态锁定。

证伪：下代闭源旗舰把 AA 差距重新拉开 >6 分；或 K3 三个月内实际部署量起不来（开源名存实亡）。
置信度：中高

② 算力需求：结构性利好推理侧与超节点形态

≥64 卡 supernode 门槛 + 1M 上下文 + 单任务数千次工具调用，把单请求算力包络抬高一个数量级；MXFP4 原生权重再确认 FP4 推理硬件路线；评测用 H20 校准说明国产/合规卡跑 3T 级模型的软件栈已被真实打磨。

证伪：超大稀疏路线被 100-200B 稠密+蒸馏路线在商业上击败（盯 MiniMax / 智谱下代旗舰参数选择）。
置信度：中高

③ 国产格局：Kimi 确立第一梯队独占位，智谱短期承压

GLM-5.2 在报告 30+ 项对比中大多垫底（DeepSWE 46.2 vs 67.5、exploit 8/36 vs 14/36）；DeepSeek V4 Pro 未进对比表。Kimi ARR 6 月破 $3 亿（3 个月 1→3 亿），"贵但最强"提价策略有性能底座支撑。

证伪：智谱/DeepSeek 三个月内发布对标 3T 级、或以 1/3 成本达 K3 90% 能力的模型；Kimi ARR 环比失速（8-9 月观察）。
置信度：中

④ 月之暗面自身：开源不伤 API 收入的结构成立

$3/$15 API 定价、$2,000 万 MaaS license 门槛、64 卡部署门槛三者互锁：能自部署的大云厂恰在收费射程内，中小客户实际只能走 API。IPO 前（传闻投前估值 $315 亿）这是一套为资本市场准备的完整故事。

证伪：出现绕开 license 的大规模第三方蒸馏/量化再分发商用化（盯 HF 衍生模型生态）。
